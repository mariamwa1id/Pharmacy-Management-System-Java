Pharmacy Management System (Java)

Console-based Pharmacy Management System developed in Java.

 Features
- Search for medicines in the inventory
- Add and delete medicines dynamically
- Calculate total cost based on price and quantity
- Generate purchase receipt
- Create account and login system
- Input validation

 Technologies
Java • OOP • Arrays • Console UI

 How to Run
1. Compile the program:
   javac PharmacySystem.java

2. Run the program:
   java PharmacySystem
